\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}
Цель курсовой работы достигнута: был разработан статический веб-
сервер. Для достижения поставленной цели были выполнены следующие
задачи:
\begin{itemize}
	\item проанализирована архитектуру компьютерной сети, протоколы и системные вызовы; 
	\item описаны основные компоненты и алгоритмы работы веб-сервера.
	\item реализован сервер;
	\item проведено нагрузочное тестирование разработанного сервера;
\end{itemize}
На основе исследования была определена оптимальная конфигурация разработанного сервера.
