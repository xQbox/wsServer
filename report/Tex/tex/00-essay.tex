\chapter*{РЕФЕРАТ}
\addcontentsline{toc}{chapter}{РЕФЕРАТ}

Расчетно-пояснительная записка 38 с., 8 рис., 1 табл., 6 источн., 1 прил.

Ключевые слова: TCP, HTTP, статический сервер, нагрузочное тестирование.

Цель работы --- разработка сервера для отдачи статического содержимого
с диска по протоколу HTTP.

В ходе выполнения работы были описаны основные компоненты веб-
сервера и принципы его работы, описан алгоритм работы статического сервера,
реализован статический сервер и проведенл нагрузочное тестирование разра-
ботанного программного обеспечения.

По результатам исследования был сделан вывод о том, 
что оптимальная конфигурация по числу потоков слушателей и потоков обработчиков  равна (2, 8).
